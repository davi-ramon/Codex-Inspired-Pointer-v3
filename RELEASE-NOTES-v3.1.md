# Codex-inspired Pointer v3.1.0

Atualização gratuita para Windows 10/11:

- Texto, ajuda, carregamento, redimensionamentos e as outras funções padrão agora recebem a mesma escala do ponteiro normal. O movimento de retorno acompanha a função ativa.
- O auxiliar de movimento é acompanhado por um iniciador que o reabre após uma falha. Uma tarefa de login com atraso de 20 segundos ajuda a manter a animação depois de entrar no Windows.
- O pacote inclui **CursorTestPanel.exe**, com áreas para testar as 17 funções e um mapa demonstrativo com mão aberta e fechada. O configurador ganhou o botão **Testar ponteiros**.

**Como atualizar:** baixe `Codex-Inspired-Pointer-Windows-v3.1.zip`, extraia tudo, abra `Configure.exe` e clique em **Aplicar ao Windows**. Veja o [guia completo](https://github.com/davi-ramon/Codex-Inspired-Pointer-v3#baixar-e-instalar).

O esquema do Windows não altera cursores desenhados diretamente por outros aplicativos, como alguns mapas e páginas web. Projeto independente inspirado no visual do Codex; não é um produto oficial da OpenAI.
